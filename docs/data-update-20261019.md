# ข้อมูลสรุปศิลา · 19 ตุลาคม 2569

Revision1.5 · เอกสารข้อมูลประกอบรุ่น ผลเผยแพร่ตรวจแยกจาก GitHub Pages build และ live-byte receipt เอกสารนี้เผยเฉพาะยอดรวมที่ตรวจแล้ว ไม่มีไฟล์ต้นทางรายบุคคล

ข้อมูลGISเดิม16ชุด รวมมุมมองสรุป5ชุดเป็น21ชุดและภาพรวม หน้าแรกยังเป็นรูปอาคาร ยอดใหม่ไม่เปลี่ยนตามหมู่บ้าน/เขตเลือกตั้งบนแผนที่ กลุ่มเปราะบางเป็นกลุ่มในบัญชีดูแลที่ได้รับ ไม่ใช่ผู้ป่วยทั้งหมดของเมือง

ภาษีใช้งาน10ไฟล์: ประเมิน/ชำระ/ลูกหนี้/ประกาศ4และแบบ1/2/3/4/7/8อีก6 โดย7/8ส่งออกซ้ำที่ค่าพร้อมชนิดข้อมูล1,419,353ช่องตรงของเดิม จึงไม่นับซ้ำ แบบ1/3/7และ2/4/8มีหน่วยทรัพย์สินซ้อนชุดกัน ไม่บวกยอดข้ามแบบเป็นทรัพย์สินเพิ่ม Candidate linkageและผลต่างเนื้อที่ยังไม่รับรองภาษีผิด/ภาษีเพิ่ม

ยอดรับ23,074,139.17บาทคือเงินตามช่วงใน source รวมหลายปีภาษีและส่วนเพิ่ม ไม่ใช่ยอดประเมินปีเดียวกัน ยอดค้าง อัตราจัดเก็บหรือเงินที่โครงการทำให้เก็บเพิ่ม

## วิธีอ่านกลุ่มเปราะบาง

194หมายถึงรหัสต้นทางไม่ซ้ำ ยังไม่ยืนยันว่าเป็น194คนที่ตรวจตัวตนครบ รหัสกลุ่ม1–4ใช้ข้อความทะเบียนเดิมก่อน ความหมายยังรอยืนยันและต้นฉบับ3/4พิมพ์คำอธิบายเหมือนกัน คำ HT/DM/STROKE/DLP/CKD/CVAซ้อนกันได้ ไม่ใช่ confirmed diagnosisหรือ prevalence ไม่รวม STROKE/CVAและไม่บวกคำทั้งหมดเป็นคน เผยเฉพาะหมวดที่มีอย่างน้อย10 ไม่เผยชื่อหมวดเล็ก ยอดคงเหลือหรือ provider/village cross-tab ไม่สร้างหมุดผู้ป่วยและไม่เชื่อมข้อมูลดูแลเข้าคิวภาษี

ช่วงในแผนดูแลมีหัวปี2570และบางไฟล์อ้าง2569 ต้นฉบับแผ่นที่เรียกไตรมาส1พิมพ์ช่วงเต็มปีงบประมาณ1ต.ค.2569–30ก.ย.2570 จึงยังไม่ตีความเป็นทะเบียนผู้ป่วยปัจจุบันหรือภาระงานเยี่ยมรวมทั้งเมือง
