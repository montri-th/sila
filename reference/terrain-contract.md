# ภูมิประเทศ FABDEM แบบ 2D และ 3D ในเว็บศิลา

Revision 1.6 ปรับใน 1.8 (ขยายความสูง สีความสูง เส้นชั้นความสูง) · สัญญาข้อมูลและการแสดงผล ผลตรวจหน้าจอและผลเผยแพร่ใช้หลักฐานแยก

ปุ่ม **2D / 3D** เหนือแผนที่สลับมุมมองในหน้าเว็บศิลาได้โดยตรง ทั้งสองมุมมองใช้ FABDEM V1-2 เฉพาะ **อำเภอเมืองขอนแก่น รหัส 4001** ไม่ต้องเปิด CityMETER อีกแท็บ พื้นที่สรุปที่ผู้ใช้เลือกยังเป็นเทศบาล หมู่บ้าน หรือเขตเลือกตั้งเดิม ไม่เปลี่ยนตัวหารตามการเลื่อนกล้อง

[เปิด 2D](https://montri-th.github.io/sila/?dataset=terrain&mode=2d&lang=th) · [เปิด 3D](https://montri-th.github.io/sila/?dataset=terrain&mode=3d&lang=th)

## การใช้งานและสถานะ

- URL เก็บ `mode=2d|3d` สำหรับชุดภูมิประเทศเท่านั้น ค่าอื่นหรือชุดข้อมูลอื่นใช้ 2D รองรับการเปิดลิงก์ตรงและประวัติย้อนกลับ/เดินหน้า
- เมื่อสลับ รับศูนย์กลางและระดับซูมจากแผนที่เดิม เมื่อกลับ 2D ส่งมุมมองกลับให้แผนที่เดิม; เก็บมุมเอียงและทิศที่ใช้ใน 3D เพื่อกลับมาใช้ต่อ
- แยกสถานะความสูงกับพื้นหลังถนน/ดาวเทียมตามการโหลดจริง พื้นผิวอาจพร้อมก่อนภาพพื้นหลังครบ ไม่ใช้สถานะ mesh ready ยืนยันว่า basemap พร้อม
- ระหว่างโหลด 3D ยังเห็นแผนที่ 2D เมื่อโหลดพื้นผิวสำเร็จจึงเปลี่ยนมุมมอง ถ้า WebGL หรือข้อมูลที่จำเป็นล้มเหลว ให้กลับ 2D พร้อมข้อความและปุ่มลองใหม่ ไม่เติมข้อมูลความสูงด้วยศูนย์
- 3D แสดงภูมิประเทศและเส้นขอบเขตประเภทที่เลือกเพียงประเภทเดียว คงการปิดทึบแบบโปร่งบางนอกเขตเทศบาลตามธีม การดูรายละเอียดรายการและชั้น GIS ประกอบใช้ใน 2D; ไม่วางเวกเตอร์แบนของ Leaflet ทับฉากเอียงหรือสร้างความสูงอาคารขึ้นเอง

## วิธีสร้างพื้นผิว 3D

แผนที่ 2D เดิมใช้ Leaflet; ฉาก 3D ใช้ MapLibre GL JS 6.12.0 ที่อยู่ใน repository เดิม สร้าง mesh จากค่าความสูงจริงแทนการเอียงภาพแผนที่แบน ระดับซูมของสอง engine ต่างกันหนึ่งขั้น: Leaflet 8–22 เท่ากับ MapLibre 7–21 การแปลงกล้องทำที่ขอบ API ของ module

ตัวอ่าน DEM มาตรฐานของ MapLibre รุ่นนี้อ่าน RGB โดยไม่ใช้ alpha จึงใช้ mesh ที่ตรวจ alpha เอง: alpha 0 คือไม่มีข้อมูล ไม่ใช่ความสูง 0 วางจุดตัวอย่างที่ศูนย์กลาง pixel `(x + 0.5) / 256` ตามสัญญาต้นทาง เชื่อมรอยต่อด้วยตัวอย่างเพื่อนบ้านที่โหลดและมีข้อมูลจริงเท่านั้น ถ้ายังไม่มีเพื่อนบ้านให้เว้นช่องว่างชั่วคราว

ก่อนสร้างสามเหลี่ยม ตรวจ polygon อำเภอรวมรูและตัด cell ที่สัมผัสเส้นขอบออกแบบเผื่อด้านใน จึงอาจมีแถบโปร่งบริเวณขอบประมาณหนึ่ง native cell ไม่ขยาย DEM ออกนอกอำเภอ และไม่ข้ามช่องไม่มีข้อมูล การคำนวณใช้จุดกำเนิดเฉพาะ tile และแปลงเมตรตามละติจูดเพื่อลดความคลาดจาก GPU ที่ซูมสูง การขยายแนวดิ่งตั้งแต่ revision 1.8 ดูหัวข้อถัดไป

พื้นหลังถนน/ดาวเทียมใช้การฉายภาพจากเฟรมปัจจุบันลงพื้นผิว เมื่ออ่านภาพพื้นหลังไม่ได้หรืออยู่นอกภาพที่ฉายได้ ให้ใช้พื้นกลาง ไม่ลากสีจากขอบภาพมาแทนส่วนที่ไม่มีภาพ วิธีนี้ไม่เพิ่มรายละเอียดหรือความแม่นยำของความสูง สีตามความสูงที่เพิ่มใน revision 1.8 ดูหัวข้อ "สีความสูงและเส้นชั้นความสูง"

## ขยายความสูง (revision 1.8)

ใช้แบบเดียวกับตัวดูภูมิประเทศ CityMETER: แถบเลื่อนแบบลอการิทึม 0.5–50 เท่า ค่าต่ำกว่า 10 แสดงทศนิยมหนึ่งตำแหน่ง และโหมดอัตโนมัติที่ทำให้ความต่างระดับในมุมมอง (เปอร์เซ็นไทล์ 99 ลบ 1 ของความสูงที่วัดได้บนตาราง 24 × 24 จุด) สูงเป็นสัดส่วนหนึ่งของความกว้างภาพ ค่าเริ่ม 15% ปรับได้ 5–30% จุดที่ไม่มีข้อมูลข้ามไป ไม่ถือเป็นศูนย์ ถ้าความต่างระดับน้อยกว่า 0.5 ม. ไม่คำนวณค่าอัตโนมัติ และเปลี่ยนค่าเมื่อต่างจากเดิมเกิน 5% เท่านั้น

ค่าเริ่มต้นของศิลาคือ **อัตโนมัติ 15%** เพราะพื้นที่ค่อนข้างราบ ทั้งเขตเทศบาลสูงต่างกันราว 60 ม. ในความกว้างราว 13 กม. ภาพทั้งเทศบาลจึงขยายประมาณ 34 เท่า ส่วน 1.5 เท่าซึ่งเป็นค่าตั้งต้นแบบกำหนดเองของ CityMETER ทำให้ภาพเกือบแบน เลื่อนแถบเมื่อไรจะเปลี่ยนเป็นกำหนดเอง และ URL เก็บค่า `ex` (กำหนดเอง) หรือ `ext` (สัดส่วนที่ไม่ใช่ 15%) เส้นขอบวาดสูงกว่าผิวที่ขยายแล้ว 2 ม. บวก 1 ม. ต่อการขยายหนึ่งเท่า ความสูงที่ขยายใช้ดูรูปทรงเท่านั้น ไม่ใช่ความสูงจริงหรือระดับน้ำ

## สีความสูงและเส้นชั้นความสูง (revision 1.8)

- สีความสูง 6 ชุดจาก OH3 ตามที่เจ้าของงานขอ ค่าเริ่มต้น "ธรรมชาติ ที่ราบ" (7 สีแรกของ OH3 relief ไม่มีสีเทาขาวของยอดเขา) ใช้ HEX เดียวกันทั้งธีมสว่างและมืด เป็นข้อยกเว้นของ LDS เฉพาะชั้นนี้ เพราะ LDS ไม่มีสเกลความสูงพื้นดิน ชุดสีและที่มาอยู่ใน [terrain-palettes.json](terrain-palettes.json)
- กระจายสีตามพื้นที่เป็นค่าเริ่มต้น (แต่ละช่วงสีครอบคลุมพื้นที่พอ ๆ กัน จาก quantile 101 ค่าของความสูงในมุมมอง) หรือตามเมตร ช่วงสียืดตามความสูงที่เห็นโดยตัดบนล่าง 0.5% หรือล็อกช่วงไว้เพื่อเทียบพื้นที่ แบ่งสีเป็นชั้นเท่าระยะเส้นได้
- เส้นชั้นความสูงเลือกได้ 0.05, 0.1, 0.2, 0.5, 1, 2, 5, 10 ม. ค่าเริ่ม "ละเอียดสุดที่อ่านได้" เลือกระยะที่เล็กที่สุดซึ่งเส้นในมุมมองไม่เกิน 100 เส้น (เพดาน 200) เส้นหนาทุก 5 เส้น เส้นรองจางลงเมื่อห่างกันไม่ถึงราว 10 พิกเซล CSS และหายที่ 4 พิกเซล เส้นหนาจางที่ 8 และหายที่ 3 พิกเซล ใน 3D วัดระยะเป็นพิกเซล CSS เมื่อเปิดสีความสูง เส้นใช้หมึกเข้มสีเดียวกันทั้งธีมสว่างและมืด เพราะสีความสูงเป็น HEX เดียวกันทั้งสองธีม เมื่อปิดสี (เงาอย่างเดียว) ธีมมืดวาดเส้นสีอ่อนที่ความเข้ม 70%
- ระยะเส้นที่ละเอียดกว่าราว 1 ม. ละเอียดกว่าความคลาดเคลื่อนของ FABDEM (MAE ราว 1.12 ม. ในพื้นที่สร้างแล้ว และ 2.88 ม. ในป่า ตามผลประเมินต้นทาง) ใช้ดูรูปทรงเท่านั้น หน้าเว็บบอกไว้ในคำอธิบายสัญลักษณ์

## แหล่งข้อมูลและข้อจำกัด

ต้นทาง `FABDEM V1-2`, tile build `z12-20261007`, Terrarium 256 px, native zoom 12, display zoom สูงสุด 22 รายละเอียดต้นทางประมาณ 1 arc-second (~30 ม.) การขยายจอไม่เพิ่มรายละเอียด วันสร้าง tile 7 ตุลาคม 2026 ไม่ใช่วันสำรวจ ฐานอ้างอิงแนวดิ่ง ความแม่นยำในพื้นที่ และวันสำรวจยังไม่ประกาศ

3D ช่วยอ่านลักษณะภูมิประเทศ ไม่ใช่ระดับน้ำ การพยากรณ์น้ำท่วม หรือผลสำรวจระดับเพื่อออกแบบก่อสร้าง แสงเงาและการเอียงไม่ใช่หลักฐานความเสี่ยง

ชั้นภูมิประเทศไม่เพิ่มไฟล์ใน `data/` (revision 1.8 เปลี่ยนเฉพาะไฟล์แปลง อาคาร หมุดสำรวจ และภาษี ซึ่งไม่เกี่ยวกับ DEM) สถานะ terrain ใน catalog เดิมเป็น historical pending; consumer override เฉพาะหน่วยความจำเมื่อ metadata ภายนอกพร้อม ไม่มี raw DEM ใหม่ใน repository ไม่มีการส่งออกหรือเก็บ tile เป็นชุดข้อมูลบน host ของเว็บ
