# ภูมิประเทศ FABDEM แบบ 2D และ 3D ในเว็บศิลา

Revision 1.6 · สัญญาข้อมูลและการแสดงผล ผลตรวจหน้าจอและผลเผยแพร่ใช้หลักฐานแยก

ปุ่ม **2D / 3D** เหนือแผนที่สลับมุมมองในหน้าเว็บศิลาได้โดยตรง ทั้งสองมุมมองใช้ FABDEM V1-2 เฉพาะ **อำเภอเมืองขอนแก่น รหัส 4001** ไม่ต้องเปิด CityMETER อีกแท็บ พื้นที่สรุปที่ผู้ใช้เลือกยังเป็นเทศบาล หมู่บ้าน หรือเขตเลือกตั้งเดิม ไม่เปลี่ยนตัวหารตามการเลื่อนกล้อง

[เปิด 2D](https://montri-th.github.io/sila/?dataset=terrain&mode=2d&lang=th) · [เปิด 3D](https://montri-th.github.io/sila/?dataset=terrain&mode=3d&lang=th)

## การใช้งานและสถานะ

- URL เก็บ `mode=2d|3d` สำหรับชุดภูมิประเทศเท่านั้น ค่าอื่นหรือชุดข้อมูลอื่นใช้ 2D รองรับการเปิดลิงก์ตรงและประวัติย้อนกลับ/เดินหน้า
- เมื่อสลับ รับศูนย์กลางและระดับซูมจากแผนที่เดิม เมื่อกลับ 2D ส่งมุมมองกลับให้แผนที่เดิม; เก็บมุมเอียงและทิศที่ใช้ใน 3D เพื่อกลับมาใช้ต่อ
- แยกสถานะความสูงกับพื้นหลังถนน/ดาวเทียมตามการโหลดจริง พื้นผิวอาจพร้อมก่อนภาพพื้นหลังครบ ไม่ใช้สถานะ mesh ready ยืนยันว่า basemap พร้อม
- ระหว่างโหลด 3D ยังเห็นแผนที่ 2D เมื่อโหลดพื้นผิวสำเร็จจึงเปลี่ยนมุมมอง ถ้า WebGL หรือข้อมูลที่จำเป็นล้มเหลว ให้กลับ 2D พร้อมข้อความและปุ่มลองใหม่ ไม่เติมข้อมูลความสูงด้วยศูนย์
- 3D แสดงภูมิประเทศและเส้นขอบเขตประเภทที่เลือกเพียงประเภทเดียว คงการปิดทึบแบบโปร่งบางนอกเขตเทศบาลตามธีม การดูรายละเอียดรายการและชั้น GIS ประกอบใช้ใน 2D; ไม่วางเวกเตอร์แบนของ Leaflet ทับฉากเอียงหรือสร้างความสูงอาคารขึ้นเอง

## วิธีสร้างพื้นผิว 3D

แผนที่ 2D เดิมใช้ Leaflet; ฉาก 3D ใช้ MapLibre GL JS 6.12.0 ที่อยู่ใน repository เดิม สร้าง mesh จากค่าความสูงจริงแทนการเอียงภาพแผนที่แบน ระดับซูมของสอง engine ต่างกันหนึ่งขั้น: Leaflet 8–22 เท่ากับ MapLibre 7–21 การแปลงกล้องทำที่ขอบ API ของ module

ตัวอ่าน DEM มาตรฐานของ MapLibre รุ่นนี้อ่าน RGB โดยไม่ใช้ alpha จึงใช้ mesh ที่ตรวจ alpha เอง: alpha 0 คือไม่มีข้อมูล ไม่ใช่ความสูง 0 วางจุดตัวอย่างที่ศูนย์กลาง pixel `(x + 0.5) / 256` ตามสัญญาต้นทาง เชื่อมรอยต่อด้วยตัวอย่างเพื่อนบ้านที่โหลดและมีข้อมูลจริงเท่านั้น ถ้ายังไม่มีเพื่อนบ้านให้เว้นช่องว่างชั่วคราว

ก่อนสร้างสามเหลี่ยม ตรวจ polygon อำเภอรวมรูและตัด cell ที่สัมผัสเส้นขอบออกแบบเผื่อด้านใน จึงอาจมีแถบโปร่งบริเวณขอบประมาณหนึ่ง native cell ไม่ขยาย DEM ออกนอกอำเภอ และไม่ข้ามช่องไม่มีข้อมูล การคำนวณใช้จุดกำเนิดเฉพาะ tile และแปลงเมตรตามละติจูดเพื่อลดความคลาดจาก GPU ที่ซูมสูง ค่าเริ่มต้นขยายแนวดิ่ง 1 เท่า

พื้นหลังถนน/ดาวเทียมใช้การฉายภาพจากเฟรมปัจจุบันลงพื้นผิว เมื่ออ่านภาพพื้นหลังไม่ได้หรืออยู่นอกภาพที่ฉายได้ ให้ใช้พื้นกลาง ไม่ลากสีจากขอบภาพมาแทนส่วนที่ไม่มีภาพ วิธีนี้ไม่เพิ่มรายละเอียดหรือความแม่นยำของความสูง ไม่มีสเกลสีระดับความสูงใหม่

## แหล่งข้อมูลและข้อจำกัด

ต้นทาง `FABDEM V1-2`, tile build `z12-20261007`, Terrarium 256 px, native zoom 12, display zoom สูงสุด 22 รายละเอียดต้นทางประมาณ 1 arc-second (~30 ม.) การขยายจอไม่เพิ่มรายละเอียด วันสร้าง tile 7 ตุลาคม 2026 ไม่ใช่วันสำรวจ ฐานอ้างอิงแนวดิ่ง ความแม่นยำในพื้นที่ และวันสำรวจยังไม่ประกาศ

3D ช่วยอ่านลักษณะภูมิประเทศ ไม่ใช่ระดับน้ำ การพยากรณ์น้ำท่วม หรือผลสำรวจระดับเพื่อออกแบบก่อสร้าง แสงเงาและการเอียงไม่ใช่หลักฐานความเสี่ยง

รักษาไฟล์ `data/` ทั้ง 22 ไฟล์ตาม revision 1.5 ทุก byte รวม GIS, public municipal summary และ metadata ภูมิประเทศ สถานะ terrain ใน catalog เดิมเป็น historical pending; consumer override เฉพาะหน่วยความจำเมื่อ metadata ภายนอกพร้อม ไม่มี raw DEM ใหม่ใน repository ไม่มีการส่งออกหรือเก็บ tile เป็นชุดข้อมูลบน host ของเว็บ
